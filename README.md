# 🏦 Observation Management Portal

A secure web-based **Observation Management Portal** developed using **ASP.NET Web Forms**, **C#**, **SQL Server**, and **ADO.NET**. The application helps organizations manage audit observations efficiently through a centralized portal with secure authentication, reporting, and dashboard analytics.

---

## 📌 Features

- 🔐 Secure Login System
- 🔢 CAPTCHA Verification
- 👁️ Show/Hide Password
- 📊 Dashboard with Analytics
- 🏢 Department Management
- 📋 Observation Type Management
- 📝 Observation Entry Module
- 📑 Reports & Print Functionality
- 📜 Audit Logging
- 📅 Financial Year Selection
- 👋 Dynamic Greeting & Live Date-Time
- 📱 Responsive User Interface
- 🛡️ Session Management

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/DivyanshNodeX/Observation-Management-Portal.git
```

2. Open the solution in Visual Studio 2022.

3. Restore NuGet Packages.

4. Configure SQL Server Connection String in `Web.config`.

5. Run the project.
